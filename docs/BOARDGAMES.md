# 보드게임 추천

`/boardgames`는 웹툰·애니메이션과 나란히 제공하는 보드게임 페이지입니다. 공통 컨트롤러, 테마, 검색, 추천 개수, 로딩과 오류 처리, 상세 모달을 공유하며 인원·시간·난이도 필터는 보드게임 전용입니다.

## 목록과 출처

`data/boardgames.json`은 기존 출판사 자료 30종과 코리아보드게임즈의 공식 제품 정보 740종을 합친 **770종 목록**입니다. 요청한 보드게임 카테고리 30페이지의 1,163개 상품을 모두 확인했습니다. 해당 사이트 상품 중 740개를 수록하고 중복 상품 100개와 액세서리·확장·묶음 상품 또는 게임 여부 미확인 상품 323개를 제외했습니다. 원본에 제외 대상이 포함되어 있어 고유 게임 1,000종으로 부풀리지 않습니다.

BGG 작품 ID와 정리한 제목을 함께 비교합니다. 이미 확인된 포장·크기·일부 캐릭터 변경판은 대표 게임으로 합치고 원래 상품명은 검색 별칭으로 남깁니다. 스플렌더 듀얼, 루미큐브 워드, 우노 플립처럼 게임 방식이 다른 작품은 별도로 유지합니다. 원본 식별자·제목만으로 모든 규칙 차이를 자동 판별할 수는 없습니다. 스플렌더와 더 게임은 계속 필수 수록하며 배너는 전체 목록을 섞어 표시합니다.

- 스플렌더: [Space Cowboys 기본판 정보](https://www.spacecowboys-games.com/game/splendor/) 기준 2~4인, 약 30분, 10세 이상입니다. 듀얼 판본과 구분합니다.
- 더 게임: 숫자 카드를 오름차순·내림차순으로 놓는 원작 협력 게임입니다. [NSV Natureline 기본판 정보](https://www.nsv.de/produkt/10037989-0001-4012426830068-the-game-natureline/) 기준 1~5인, 약 20분, 8세 이상입니다. Quick & Easy와 Face to Face를 포함한 다른 판본과 구분합니다.
- 나머지 게임은 각 항목의 `url`에 출판사·공식 유통사 또는 규칙 출처를 기록합니다. 상세 화면에서 출처와 판본 안내를 확인할 수 있습니다.

시간은 출판사·공식 유통사의 표기값이며 실제 소요 시간은 설명 시간·숙련도·인원에 따라 달라집니다. 확인하지 못한 인원·연령·시간은 `null`로 보관하고 화면에 확인 필요로 표시합니다. 인원 또는 시간 제한이 있는 추천에서는 해당 값이 미확인인 게임을 제외합니다. 기존 난이도 1~3은 **오늘의 덕질 편집 분류**로 공식 평가나 BGG 평점이 아닙니다. 추가 자료에서 확인되지 않은 난이도는 0과 ‘정보 없음’으로 기록하고 난이도 제한이 있을 때 제외합니다. 가격·재고·판매 여부·제작자를 만들어내지 않습니다.

이미지는 출판사·공식 유통사가 제공하는 실제 제품 표지입니다. 기존 30종은 `assets/boardgames/`의 원본을 쓰고 추가 740종은 공식 CDN의 제품 이미지를 사용합니다. 각 항목의 `cover`, `coverSource`, `coverSourcePage`에 이미지와 공식 제품 출처를 기록합니다. 공통 배송 안내 배너가 섞이지 않도록 상품 요약의 표지 영역만 읽습니다. 표지의 권리는 각 원저작권자에게 있으며 언어·발매 지역에 따라 패키지가 다를 수 있습니다.

## 추천 조건

- 장르 여러 개는 OR, 인원·시간·난이도 조건은 AND로 적용합니다.
- 인원은 기본판의 최소~최대 범위로 제한합니다. 코드네임의 공식 ‘4~8명 이상’ 표기는 최대 인원을 임의로 고정하지 않습니다.
- 시간 상한은 확인한 표기 시간의 최댓값에 적용합니다. 난이도 상한은 편집 난이도에 적용합니다.
- 추천 수는 1~18개, 기본 6개입니다. 후보가 부족하면 가능한 수만 추천하고 요청 수와 결과 수를 표시합니다.
- 스플렌더·더 게임이 필수 수록되어도 조건을 어기면서 추천 결과에 강제로 넣지 않습니다. 예를 들어 1인 추천에서는 스플렌더를 제외하고 더 게임을 후보로 삼습니다.
- 기존 AI 호출 코드를 공유하고 검증한 후보 ID·개수·중복·추천 이유를 확인합니다. 웹툰 플랫폼 쿼터는 적용하지 않습니다. 후보가 없으면 AI를 호출하지 않습니다.

## 구현과 갱신

`services/boardgames.py`가 데이터를 정규화하고 서버 추천 조건을 적용합니다. `js/boardgames.js`가 페이지 설정을 제공하며 브라우저에서도 같은 필터를 적용합니다. 보관함은 `toonpick_saved_boardgames` 키에 별도로 저장하고 테마만 다른 분야와 공유합니다.

`python scripts/collect_boardgames.py`는 지정한 보드게임 카테고리의 실제 페이지 수를 읽고 전부 순회합니다. 액세서리·추가 상품 하위 카테고리도 따로 읽어 제외하며 최대 3개 요청만 동시에 실행합니다. BGG ID가 없는 상품도 공식 인원 정보나 검토한 제품 표지로 게임임을 확인한 경우 포함합니다. 수동으로 표지를 확인한 항목의 출처는 `data/boardgames_verified_products.json`에 기록합니다.

목록 수집 누락·요청 실패가 있으면 기존 목록을 유지합니다. 게임 데이터는 임시 파일로 작성한 뒤 교체합니다. 원본 HTML은 배포에서 제외하는 `.cache/boardgame-sources/`에 저장합니다. 새 원본이 필요하면 이 전용 캐시를 비운 후 실행합니다. `data/boardgames_collection_report.json`에는 전체 상품 수와 수록·중복·제외 개수 및 개별 사유를 남깁니다.

`python scripts/sync_public.py`를 실행하면 보드게임 HTML·정규화한 `data/boardgames_catalog.json`을 생성하고 `public/`까지 동기화합니다. 빌드 시 로컬 표지 파일 존재를 확인합니다. AI 후보는 인원·시간·난이도 조건 적용 후 최대 90종으로 제한해 전송량과 응답 지연을 줄입니다. 일반 탐색은 정적 스냅샷으로도 동작하며 AI 추천은 개발 서버가 필요합니다.

- 목록: `GET /api/generate?resource=boardgame_catalog`
- 추천: 기존 `POST /api/generate`에 `type=boardgame`, `genres`, `mood`, `notes`, `players`, `maxMinutes`, `difficulty`, `count`를 전달합니다.
- 로컬·Vercel 모두 `/boardgames` 직접 접근과 새로고침을 지원합니다.
