# 오늘의 덕질 시연 가이드

## 시연 순서

1. `python dev_server.py` 실행 후 표시된 로컬 주소를 엽니다.
2. 자동 수집 작품 수와 최초 24개 작품을 확인하고, 더 보기로 다음 작품을 불러옵니다.
3. 국내 플랫폼 모아보기의 조회 상태와 공식 링크를 확인하고, 플랫폼·로맨스·힐링 등 조건을 조합해 목록을 좁힙니다.
4. 제목 또는 작가 이름을 검색하고 검색 결과가 없는 상태도 확인합니다.
5. 취향과 추가 요청을 입력해 AI 추천을 제출합니다. 기본 네이버 2·카카오 2·기타 2 배분과 작품별 추천 이유를 확인합니다. 플랫폼 제한·후보 부족 시 재배분되는지, 수집·검색·후보 수와 공식 검색 발견 표시도 확인합니다.
6. 작품 상세 모달에서 줄거리와 공식 작품 링크를 확인합니다.
7. 여러 작품을 보관함에 넣고 새로고침 후 유지되는지 확인합니다.
8. 작품 삭제, 다크 모드 전환, 모바일 화면을 확인합니다.

## 캡처 권장 화면

- 데스크톱 메인 화면
- 취향 선택 모달과 조건이 적용된 추천 목록
- 작품 상세 모달
- 내 보관함
- 모바일 화면 및 다크 모드

## 검증 명령

- `node --test tests/services.test.cjs`
- `node --check js/app.js`
- `node --check js/api.js`
- `node --check js/storage.js`
- `python -m unittest discover -s tests -p 'test_*.py' -v`

화면 수정 후 `python scripts/sync_public.py`를 실행해 Vercel 정적 파일도 맞춥니다. 전체 수집은 `python scripts/update_catalog.py`, 네이버웹툰 이외의 갱신은 `python scripts/update_platforms.py`로 실행합니다. 서버는 24시간이 지난 목록을 요청 시 백그라운드에서 갱신합니다. AI는 기존 AI_API_KEY·AI_API_BASE_URL·AI_MODEL 전역변수를 사용합니다. 19개 서비스 중 13개는 공개 작품 정보를 자동 조회하고, 나머지는 공식 사이트 연결을 제공한다는 점을 설명합니다. [플랫폼 연결 문서](PLATFORMS.md)에 서비스별 범위가 있습니다.
