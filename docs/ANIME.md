# 국내 서비스 애니메이션 추천

`/anime`는 공통 화면과 컨트롤러를 공유하는 별도 진입점입니다. `js/anime.js`가 라프텔·넷플릭스의 링크와 이미지 호스트를 등록합니다. `python scripts/sync_public.py`로 세 분야의 HTML과 배포 파일을 함께 갱신합니다.

## 데이터와 조회

`data/anime_domestic.json`은 라프텔 공개 검색 목록 9,566개와 넷플릭스 한국 애니메이션 공식 목록 303개, 총 **9,869개 플랫폼별 작품 항목**을 담습니다. 이는 고유 프랜차이즈 수가 아닙니다. 시즌·극장판·더빙판 및 플랫폼별 중복 항목을 포함합니다. 작품 등록과 현재 재생 가능 여부를 구분해 표시하며 재생 권한·국내 판권·등급은 공식 서비스를 확인해야 합니다.

- 모든 작품은 한국어 서비스 제목, 공식 작품 URL, 실제 제공 표지, 확인된 형식·장르만 저장합니다. 누락된 줄거리·제작사·등급은 추정하지 않습니다.
- 검색·장르·플랫폼·형식·상태 조건은 전체 스냅샷에 먼저 적용하고 120개씩 응답합니다. 브라우저는 24개씩 표시하며 더 보기로 다음 페이지를 요청합니다.
- 처음에는 라프텔과 넷플릭스 항목을 교차 배치합니다. 배너 후보 60개는 전체 목록에서 플랫폼별 30개씩 무작위로 골라 전달합니다.
- 선택한 라프텔 작품의 줄거리는 상세 화면에서 해당 작품만 조회하며 최대 128개 응답을 약 10분 단위로 캐시합니다. 영상·로그인·계정 데이터는 수집하지 않습니다.
- AI는 전체 목록의 조건을 적용한 뒤 감상 가능 표시가 있는 후보를 우선하고, 제목으로 확인 가능한 시즌·더빙·동일 작품 중복을 줄여 60~72개를 검토합니다. 원본 정보가 적으면 줄거리를 만들어내지 않도록 지시합니다. 제목 표기만으로 찾기 어려운 시리즈 관계는 남을 수 있습니다.
- 보관함은 `toonpick_saved_anime`에 저장합니다. 기존 AniList 보관 항목은 출처가 바뀌어 현재 목록에서 표시되지 않을 수 있으며 저장 데이터 자체는 삭제하지 않습니다.

## 수집 갱신

`python scripts/collect_domestic_anime.py`는 공개 검색 페이지를 천천히 읽고 작품 ID로 수집 중복을 제거합니다. 원본 응답은 배포에서 제외되는 `.cache/domestic-anime/`에 저장합니다. 새 원본으로 다시 수집하려면 이 전용 캐시를 비운 뒤 실행합니다. 넷플릭스 작품 정보 조회는 최대 3개 동시 요청으로 제한합니다. 수집 이후 `python scripts/sync_public.py`를 실행합니다.

## 엔드포인트

- `GET /api/generate?resource=anime_catalog`: `query`, `page`, `mood`, `status`와 반복 가능한 `genre`, `format`, `platform`을 지원합니다.
- `GET /api/generate?resource=anime_detail&id=...`: 저장된 작품 ID만 허용합니다. 요청자가 임의의 외부 URL을 지정할 수 없습니다.
- `POST /api/generate`: `type=anime`, `genres`, `formats`, `platforms`, `status`, `mood`, `notes`, `count`를 전달합니다. 추천 수는 기본 6개, 1~18개입니다.

AI 자격증명은 기존 서버 환경변수만 사용합니다. 일반 목록 응답은 전체 파일 대신 페이지와 소규모 배너 후보만 포함해 서버리스 응답 크기를 제한합니다.

## 공통 배너

`js/experience.js`는 실제 카드가 이어진 네이티브 가로 스크롤 목록을 사용합니다. 한 페이지에 3장, 자동 이동은 약 7초 간격입니다. 버튼·좌우 방향키·모바일 스와이프를 지원합니다. 최근 페이지와 다음 페이지를 포함해 최대 12페이지(36장)만 DOM에 유지합니다. 웹툰 플랫폼과 애니메이션 시리즈의 편향을 줄이는 추첨을 유지합니다. 화면 밖·백그라운드·호버·포커스·모달·사용자 정지 상태에서는 자동 재생을 멈추며 모션 감소 설정에서는 수동으로만 이동합니다.
