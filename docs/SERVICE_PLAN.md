# 서비스 기획서: 오늘의 덕질

## 목적

웹툰을 고르는 시간을 줄이고 장르와 현재 기분에 맞는 다음 작품을 발견하게 합니다. 작품 정보를 확인한 후 공식 플랫폼으로 이동해 감상하며, 다음에 읽을 작품은 브라우저 보관함에 모읍니다.

## 주요 사용자 흐름

1. 홈에서 에디터 추천 작품과 분위기별 선택지를 확인합니다.
2. 플랫폼, 장르, 검색어, 연재 상태로 목록을 좁히거나 취향 추천 창에서 여러 플랫폼·장르와 분위기를 선택합니다.
3. 표지 또는 제목을 눌러 줄거리, 작가, 연령, 연재 정보를 확인합니다.
4. 북마크로 보관하거나 공식 플랫폼 페이지로 이동합니다.
5. 내 보관함에서 저장한 작품을 다시 확인하고 삭제할 수 있습니다.

## 구현 범위

카탈로그는 네이버웹툰 연재·완결 목록과 국내 플랫폼의 공개 검색·대표 목록에서 수집합니다. 비네이버 검색은 18개 장르·주제와 다음 페이지로 확장하고 카카오페이지·봄툰의 완결 전용 검색도 수집합니다. 24시간 갱신과 마지막 정상 스냅샷 유지로 수동 등록 부담을 줄입니다. 추천 요청마다 선택 플랫폼을 병렬 조회해 신규 후보를 보완합니다. 네이버웹툰은 최대 3개 질의, 나머지는 주요 키워드 1개를 사용합니다. AI는 기존 AI_API_KEY·AI_API_BASE_URL·AI_MODEL을 사용하며, 플랫폼별로 분배한 후보 기본 36개·최대 72개에서 취향·요청·줄거리를 분석해 사용자가 선택한 1~18개 작품과 이유를 반환합니다.

일반 탐색에서 장르 여러 개는 OR, 분위기·연재 상태·검색어·플랫폼은 AND로 조합합니다. AI 추천의 플랫폼·장르·연재 상태는 서버에서 강제하며, 분위기는 AI가 줄거리와 함께 판단합니다. 수집·검색·후보 수와 수집 시점을 표시하고 검색 질의·원본 주소를 남깁니다. 후보가 없으면 모델을 호출하지 않습니다. 연결한 19개 서비스 중 13개는 자동 조회를 제공하며, 나머지 6개는 공식 사이트로 연결합니다. 전체 범위는 [플랫폼 연결 문서](PLATFORMS.md)에 기록합니다.

추천 수는 1~18개이며 기본 6개는 네이버 2개·카카오 2개·기타 2개로 배분합니다. 기타는 가능한 경우 서로 다른 플랫폼에서 고릅니다. 네이버웹툰·시리즈와 카카오웹툰·페이지는 각각 한 그룹으로 합산합니다. 후보 부족 시 사용자가 고른 조건을 유지하며 남는 자리를 재배분합니다. 최종 AI 응답의 배분과 작품 중복을 서버에서 검증합니다. 일반 목록의 추천순도 플랫폼을 번갈아 배치합니다. 대기 중에는 회전 표시·대기 막대·경과 시간과 창 밖의 진행 표시를 제공하며 실패 시 입력 상태를 복구합니다.

## 기술 구조

기존 Vanilla HTML/CSS/JavaScript를 유지합니다. 카탈로그는 요청을 공유하는 Promise로 한 번 읽고, 정규화한 검색 문자열을 재사용합니다. 화면은 24개씩 표시하며 검색·필터는 전체 목록에 적용합니다. 반복 카드의 클릭 이벤트는 문서에 위임하고, 이미지는 크기를 예약해 지연 로드합니다. 모달은 네이티브 dialog를 사용합니다.

기존 StorageManager와 ApiService의 공개 이름은 유지합니다. AI 추천은 기존 POST /api/generate에 type=webtoon으로 요청하며, 브라우저에 인증 정보를 전달하지 않습니다. 서버는 후보에 없는 ID·중복 ID·잘못된 형식을 거절하고, 인증·한도·시간 초과 오류를 명시합니다. 루트와 public은 동기화 스크립트로 동일하게 유지합니다.

## 데이터와 저작권

원본 작품 주소와 메타데이터 주소를 카탈로그에 보관합니다. 작품 이미지·줄거리의 권리는 각 저작권자에게 있으며 이용 조건은 공식 페이지에서 안내합니다. 공개 정보에 없는 장르·연재 상태를 추정하지 않습니다. 서버는 요청 시 갱신 주기를 확인해 백그라운드에서 목록을 갱신하며, 관리용 스크립트로 즉시 갱신할 수도 있습니다.

## 검증 기준

- 조건에 맞는 작품만 표시하고 검색·정렬 후 원본 순서가 유지됩니다.
- 저장·중복 저장·삭제·손상된 저장 데이터·저장 실패가 정상 처리됩니다.
- 재시도 시 실패한 카탈로그 요청이 복구됩니다.
- AI 오류를 임의 결과로 대체하지 않고, 유효한 작품 ID와 추천 이유만 표시합니다.
- 데스크톱·모바일에서 가로 넘침 없이 탐색하고 모달을 조작할 수 있습니다.
