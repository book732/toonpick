# 국내 플랫폼 연결 범위

공식 주소를 확인한 국내 웹툰·만화 19개 서비스를 등록했습니다. ‘등록’과 ‘자동 수집 가능’은 구분하며, 접속·응답 형식에 따라 화면의 조회 상태가 달라질 수 있습니다.

범용 웹검색·플랫폼 제휴 API 계약·서비스의 모든 작품 수집을 의미하지 않습니다. 제한된 정보가 있는 경우 존재하지 않는 작품이나 연결 상태를 만들어내지 않습니다.

## 식별과 검증

네이버웹툰의 기존 숫자 ID는 유지하고 다른 서비스는 `플랫폼키:URL해시`를 사용합니다. 서버·클라이언트 모두 플랫폼의 작품 주소와 공식 이미지 호스트를 검증합니다. 기존 보관함 데이터와 새 플랫폼 작품을 함께 저장할 수 있습니다.

연재 상태가 공개 응답에서 확인되지 않으면 ‘확인 필요’로 표시합니다. 이러한 작품은 완결 전용 조건에 포함하지 않습니다. 공개 제목·태그·줄거리만 AI에 전달하며 플랫폼 선택과 장르·연재 상태는 서버에서 적용합니다.

추천 개수는 1~18개이며 기본 6개는 네이버 2개·카카오 2개·기타 2개로 배분합니다. 네이버웹툰·시리즈와 카카오웹툰·페이지는 각각 같은 그룹으로 합산합니다. 개수가 달라지면 그룹별 자리를 고르게 배분하고 기타 플랫폼도 가능한 한 다양하게 고릅니다. 후보가 부족하거나 플랫폼을 직접 제한한 경우에는 조건을 유지한 채 남는 자리를 재배분합니다. 동일 제목의 개정판 등은 후보에서 중복 제거하며, AI 응답이 계산된 배분을 어기면 서버가 거절합니다. 일반 목록의 추천순도 플랫폼을 번갈아 배치합니다.

## 운영

공개 검색은 18개 장르·주제로 확대했고 JSON 검색은 검색어당 최대 8페이지, HTML 검색은 최대 4페이지를 확인합니다. 같은 페이지가 반복되면 추가 조회를 중단합니다. 카카오페이지·봄툰은 완결 전용 검색도 수집합니다. 목록을 제공하는 방식이 달라 플랫폼별 수집 수는 동일하지 않으며, 공개 조회가 제한된 서비스는 계속 공식 링크를 제공합니다.

`python scripts/update_platforms.py`로 네이버웹툰 이외의 정보를 수집하고, `python scripts/sync_public.py`로 배포 파일을 동기화합니다. 플랫폼 주소·경로·이미지 허용 목록은 `data/platforms.json`, 서비스별 수집 코드는 `services/platforms.py`에 있습니다.

자동 조회에 실패해도 기존 스냅샷과 공식 사이트 이동 링크는 유지합니다. 검색·목록의 내부 형식이 변경되면 해당 어댑터 수정이 필요합니다.
